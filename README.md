# 3D Printing Knowledge Wiki 🖨️📚

คลังความรู้ ข้อมูลสเปก และคู่มือเกี่ยวกับ **3D Printing (FDM, Resin, Powder, Materials & Components)** รวบรวมข้อมูลที่เป็นประโยชน์สำหรับผู้ใช้งานเครื่องพิมพ์ 3 มิติในประเทศไทยและทั่วไป

## 📑 เนื้อหาและหมวดหมู่ (Categories)
- **FDM 3D Printers**: ข้อมูลสเปกเครื่องพิมพ์แบบ FDM/FFF, โครงสร้าง และระบบการเคลื่อนที่
- **FDM Tool Changer & DIY**: เครื่องพิมพ์ระบบสลับหัวฉีด และกลุ่มเครื่อง DIY / Open Source Kits
- **Filament & Materials**: คุณสมบัติทางความร้อนและเชิงกลของเส้นพลาสติก (PLA, PETG, ABS, ASA, TPU, Nylon, PEEK ฯลฯ)
- **Resin & Powder Printers**: เครื่องพิมพ์เรซิน (SLA/MSLA/DLP) และเครื่องพิมพ์ระบบผง (SLS)
- **Hardware & Components**: เมนบอร์ดควบคุม (Controller Boards), สเต็ปเปอร์มอเตอร์ (Stepper Motors) และไดรเวอร์ (Stepper Drivers)
- **Accessories**: กล่องอบเส้น (Filament Dryers) และระบบมัลติคัลเลอร์ (Multi-Material Systems - MMS)
